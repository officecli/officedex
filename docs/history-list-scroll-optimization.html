落到正式代码时的改动点

  1. 把每行从纯 flex 改成稳定列：grid-template-columns: 22px minmax(0, 1fr) 14px 24px，图标、标题、状态点、删除按钮各自有固定槽位。
  2. 删除按钮不要再用 display: none 隐藏，改为 opacity: 0、pointer-events: none；hover/focus 时只改透明度。
  3. 固定行高和垂直节奏：列表用 grid-auto-rows: 40px 或 item height: 40px，hover 不改变 padding、font-size、border、gap。
  4. active/hover 只改颜色和背景，不改 font-weight；字体粗细变化会改变文本宽度，长标题省略号会跟着抖。
  5. 滚动容器增加 scrollbar-gutter: stable 和 overscroll-behavior: contain，避免滚动条出现/消失或滚动串联带来的侧向变化。
