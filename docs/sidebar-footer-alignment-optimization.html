左下角导航按钮垂直居中优化方案

红线是每个按钮的几何中心。左侧复现当前容易出现的问题：图标和文字直接放在 flex 行里，且“设置”的分割线与上内边距在按钮本体上。右侧把图标放进固定盒子，文字使用稳定行高，分割线移到导航组容器上。

当前问题复现 flex 行 + 图标字体基线 + settings 自带 padding-top
offset 0px
优化后方案 固定 48px 行高 + 32px 图标盒 + 分割线在 nav 容器上
offset 0px

落到正式代码时的改动点

  1. 把 footer 按钮从 display:flex 改成两列 grid：grid-template-columns: 28px minmax(0, 1fr)，让图标和文字各自有稳定垂直参考。
  2. 给图标单独包一层固定盒：.nav-item .anticon { width: 28px; height: 28px; display: grid; place-items: center; line-height: 1; }，不要让 icon font 的基线参与行内对齐。
  3. 文字使用显式行高：.nav-item > span:not(.anticon) { line-height: 22px; }，必要时只对中文视觉中心加 translateY(1px)。
  4. 不要把设置项的分割线和 padding-top 放在按钮本体上；分割线移到 .sidebar-footer-nav 或单独 wrapper，按钮自身仍保持固定高度。
  5. active 背景只覆盖按钮自身的固定高度，不影响行内布局；hover/active 不改变 padding、height、line-height。
