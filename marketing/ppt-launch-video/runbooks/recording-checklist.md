# Recording Checklist

- Use English UI and a clean workspace.
- Keep onboarding and update prompts out of the recording.
- Keep the full OfficeDex window at 1920×1080.
- Use only the exact magic prompt and exact timeline edit sentence.
- Preserve visible user confirmation clicks.
- Reject any run that opens the generic question composer.
- Reject any run that skips a generation stage.
- Reject any run with Chinese text, private data, poor slide alignment, or unreadable content.
- Capture the final vertical roadmap after the AI edit has been applied.
